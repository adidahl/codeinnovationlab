# codeinnovationlab.no

One-page site for Code Innovation Lab (Next.js, light theme only, same style as Vibefort).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Deploy: import the repo in Vercel (framework preset Next.js), then add `codeinnovationlab.no` under Domains and point the DNS records at one.com to what Vercel shows.
